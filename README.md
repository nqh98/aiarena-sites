# aiarena-sites

Site configs (CSS selectors, language-independent choice keys, error regexes) for the AI Debate Coordinator
Chrome extension. The extension downloads `sites.json` periodically so it keeps working when the Qwen, Gemini
and Grok web UIs change, without a new extension release.

Data only, no code. `sites.json` is published automatically from the extension's main repo; do not edit it here.
